# CCNA Labs Portfolio

A collection of hands-on Cisco Packet Tracer labs completed during my CCNA studies. Each lab includes the topology, configuration, and verification steps.

## 📋 Labs Included

| Lab | Topic | Skills Demonstrated |
|-----|-------|---------------------|
| ACL | Access Control Lists | Traffic filtering, security |
| DHCP | Dynamic Host Configuration | IP assignment, server config |
| HSRP | Hot Standby Router Protocol | Redundancy, high availability |
| NAT | Network Address Translation | PAT, static NAT, NAT overload |
| NTP & LLDP | Network Time & Discovery | Time sync, neighbor discovery |
| OSPF | Open Shortest Path First | Dynamic routing, areas |
| OSPF2 | Advanced OSPF | Multi-area, summarization |
| SSH | Secure Shell | Remote management, security |
| Telnet | Telnet | Legacy remote access |

## 🛠️ Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI
